# 🩺 What is Diabetic Retinopathy?

Diabetic Retinopathy (DR) is an eye disease caused by diabetes.

High blood sugar damages retinal blood vessels over time and may lead to:
- Blurry Vision
- Floaters
- Vision Distortion
- Blindness in Severe Cases

Early detection is extremely important to prevent permanent vision loss.
